Audio Widget

The <audio-widget> is a custom web component styled as a glass panel with a frosted glass edge. It's fixed to hover over the UI at the bottom right. Here is the code structure used for it:

<audio-widget 
    station="My Station" 
    track="Track Name" 
    artist="Artist"
    cover="image-url.jpg">
</audio-widget>

<script>
    const widget = document.querySelector('audio-widget');
    widget.addEventListener('play', () => console.log('Playing...'));
    widget.addEventListener('pause', () => console.log('Paused.'));
    widget.addEventListener('forward', () => console.log('Next track'));
    widget.addEventListener('back', () => console.log('Previous track'));
    widget.addEventListener('settings', () => console.log('Settings'));
</script>
