Ohrbob Logo Component

A highly configurable logo component that scales with font-size and supports multiple layouts.

Text Only

Scales exactly with the parent's font size.

ohrbob 
<div style="font-size: 2rem;">
  <div class="ohrbob-logo">
    <span class="ohrbob-logo-text">
      <span class="char-1">o</span><span class="char-2">h</span><span class="char-3">r</span><span class="char-4">b</span><span class="char-5">o</span><span class="char-6">b</span>
    </span>
  </div>
</div>
Logo Left (Inline)

Icon scales automatically to match line-height of text.

ohrbob 
<div style="font-size: 3rem;">
  <div class="ohrbob-logo ohrbob-logo-left">
    <span class="ohrbob-logo-icon">
      <img src="ohrbob-logo.svg" alt="Icon">
    </span>
    <span class="ohrbob-logo-text">
      <span class="char-1">o</span><span class="char-2">h</span><span class="char-3">r</span><span class="char-4">b</span><span class="char-5">o</span><span class="char-6">b</span>
    </span>
  </div>
</div>
Logo Above (Stacked)

    <span class="ohrbob-logo-icon">

Logo Above (Width Controlled)

Using CSS container queries (container-type + cqi) to scale by width instead of font-size.

  <div style="font-size: 15cqi;">
    <div class="ohrbob-logo ohrbob-logo-above">

Audio Widget

The <audio-widget> is a custom web component styled as a glass panel with a frosted glass edge. It's a full-width player bar docked to the bottom of the viewport. Here is the code structure used for it:

<audio-widget 
    station="My Station" 
    track="Track Name" 
    artist="Artist"
    cover="image-url.jpg">
</audio-widget>

<script>
    const widget = document.querySelector('audio-widget');
    widget.addEventListener('play', () => console.log('Playing...'));
    widget.addEventListener('pause', () => console.log('Paused.'));
    widget.addEventListener('forward', () => console.log('Next track'));
    widget.addEventListener('back', () => console.log('Previous track'));
    widget.addEventListener('settings', () => console.log('Settings'));
</script>
